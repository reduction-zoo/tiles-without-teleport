# Prepare evidence

Prepared 2026-09-26. The fixed corpus contains 120 distinct 3-SAT formulas: 20 hand cases and 100 seeded random cases, with 64 YES and 56 NO. Formula sizes range from 0 to 6 variables. `generate_cases.py` fixes inputs and seeds before any candidate construction.

The move rule follows [the primary Tiles definition](https://arxiv.org/html/2509.10846v1): start on a tile, then move only to another tile with a currently shared feature, deleting every feature shared by that pair. No teleport is permitted. Run `uv sync --locked` and `uv run --locked python campaigns/tiles-without-teleport/work/check.py --self-test`. It first runs the copied `research/validate_preparation.py`, regenerates source formulas, recomputes Z3 SAT labels, validates assignments directly, and crosschecks with exhaustive Boolean assignments. The target oracle performs complete depth-first state search. Every move deletes at least one feature occurrence from each of two tiles, so the finite state search terminates; exhaustion conclusively proves NO-SOLUTION. Direct replay validates returned paths. A breadth-first state-set search agreed on 150 seeded target puzzles: 50 YES and 100 NO, with up to five tiles and four features. Hand cases cover a two-tile move, an odd feature, an empty board, a chain, invalid sets and forbidden self-moves. A deliberately incorrect candidate returning a feasible two-tile target and always extracting NO-SOLUTION was rejected.

Oracle: CPython 3.12.14 and locked `z3-solver` 4.16.0.0 for the source; standard-library exhaustive search for the target. Only Z3 `unsat` yields source NO; `unknown` raises. Target search is exponential and checked only on finite small instances. The candidate gate checks at most three target paths per source instance, so it does not prove universal recovery. No reduction or solution is claimed; zero construction rounds were authorized for this setup.
